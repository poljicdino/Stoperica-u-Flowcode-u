# Digital Stopwatch in Flowcode

Projekat digitalne štoperice izrađen u Flowcode okruženju.

## Opis projekta

Ovaj projekat implementira funkcionalnu digitalnu štopericu sa:
- start funkcijom
- stop funkcijom
- reset funkcijom
- prikazom vremena

## Korištene tehnologije

- Flowcode
- Elektronika
- Mikrokontroleri

## Struktura projekta

- `flowcode/` → Flowcode projekat
- `docs/` → izvještaj projekta
- `images/` → slike i simulacije

## Pokretanje projekta

1. Otvoriti `.fcfx` fajl u Flowcodeu
2. Pokrenuti simulaciju
3. Testirati funkcije štoperice
